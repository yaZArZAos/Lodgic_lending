Политика конфиденциальности

Как Lodgic обращается с вашими данными
Документ в разработке. Полная редакция политики конфиденциальности будет опубликована в ближайшее время. Ниже — основные принципы работы с данными.

1. Какие данные мы собираем

Сервис Lodgic собирает минимально необходимый объём данных:

  • Telegram ID — для идентификации пользователя и учёта лимитов;
  • Имя пользователя (если указано) — для отображения в интерфейсе;
  • Параметры оценок — метро, тип жилья, площадь, расстояние до метро, текущая цена. Используются для расчёта и сохранения истории;
  • Данные об оплате — только факт оплаты и идентификатор транзакции. Реквизиты карт мы не видим и не храним — они обрабатываются платёжной платформой Lava.top.

2. Зачем мы собираем данные

  • Оказание услуг по оценке цен и предоставлению аналитики;
  • Учёт использования бесплатного лимита и активация платной подписки;
  • Сохранение истории оценок для вашего удобства;
  • Обработка платежей и подтверждение оплат;
  • Связь с вами при возникновении вопросов по работе Сервиса.

3. Кому мы передаём данные

Мы не продаём и не передаём ваши данные третьим лицам, за исключением:

  • Telegram — для работы бота (сообщения обрабатываются через API Telegram);
  • Lava.top — для обработки платежей;
  • По требованию закона — если данные запрошены уполномоченными органами в установленном порядке.

4. Хранение данных

Данные хранятся на защищённых серверах. Мы используем стандартные меры безопасности для предотвращения несанкционированного доступа. Данные хранятся в течение срока, необходимого для оказания услуг, после чего удаляются или обезличиваются.

5. Ваши права

Вы вправе:

  • Запросить информацию о том, какие данные о вас хранятся;
  • Потребовать удаления ваших данных и истории оценок;
  • Отказаться от использования Сервиса в любой момент.

Для реализации любого из прав обратитесь по контакту @Lodgic_Ceo.

6. Cookies и аналитика

Telegram-бот не использует cookies. На этом лендинге аналитические счётчики (Яндекс.Метрика, Google Analytics и подобные) в настоящее время не установлены.

7. Изменения политики

Мы можем обновлять настоящую политику. Актуальная версия всегда доступна на этой странице. Продолжение использования Сервиса после публикации изменений означает согласие с новой редакцией.

8. Контакты

По любым вопросам, связанным с обработкой данных, обращайтесь: @Lodgic_Ceo (Telegram)
